## 📋 Выполненные задания

### 1. Тестирование функции `is_even(number)`
* Реализована проверка чётности целых чисел.
* Применена параметризация `@pytest.mark.parametrize` для чётных, нечётных и отрицательных чисел.
* Реализовано отдельное негативное тестирование (проверка выброса `TypeError` при передаче строк, float, `None` и коллекций).

### 2. Тестирование функции `calculate_area(length, width)`
* Реализован расчёт площади прямоугольника.
* Применена параметризация с несколькими параметрами для комбинаций длины и ширины (дробные числа, граничные значения).
* Добавлена проверка на обработку отрицательных параметров (`ValueError`).

### 3. Тестирование функции `classify_triangle(a, b, c)`
* Реализовано определение типа треугольника: `равносторонний`, `равнобедренный` или `разносторонний`.
* Написана параметризация для всех типов треугольников.
* Добавлены негативные тесты на проверку неравенства треугольника и некорректных сторон ($\le 0$).

### 4*. Доработка задания из КТ-2
* Доработана функция расчёта стоимости со скидкой `calculate_discount(price, discount)`.
* Добавлена параметризация для корректных расчётов и валидации некорректных значений скидки/цены.
